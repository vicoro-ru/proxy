strongswan — основной мета-пакет. Устанавливает демон (службу) и базовые конфигурационные файлы для работы протокола IKEv2 (защищенный обмен ключами).
pki — утилита для управления сертификатами (PKI — Public Key Infrastructure, встроена в strongswan). Позволяет создавать собственный удостоверяющий центр (CA), генерировать закрытые ключи и выпускать сертификаты для сервера и клиентов.


https://www.vitaliy.org/post/7243

libcharon-extra-plugins — набор дополнительных плагинов для основного демона (Charon). Отвечает за расширенную поддержку алгоритмов шифрования, хеширования и специфических сетевых протоколов.
libcharon-extauth-plugins — плагины для внешней аутентификации. Позволяют проверять логины и пароли пользователей через сторонние системы, такие как PAM, RADIUS или LDAP.
libstrongswan-extra-plugins — дополнительные библиотеки системного уровня. Обеспечивают поддержку специфических криптографических модулей (например, работу с базами данных или расширенные методы шифрования на уровне ядра).
